# Start Schedule — v3-targeted (position D), seeded 20260825

50 episodes: 30 CLEAN + 20 targeted-recovery (6× ROT-20°, 4× ROT-45°,
5× NUDGE, 5× LEFT-MIMIC), interleaved by seeded shuffle (no two same-type
recovery demos adjacent; episodes 1–2 clean to warm in).

**Rules (same as v2 + additions):**
- Every episode: decisive. If a take feels hesitant → `r`, redo it.
- CLEAN quality bar = v2: grasp ≈3.5 s from start, no hover.
- LEFT-MIMIC: exactly ONE beat of hover left of the cap, then a committed
  rightward correction into the grasp — the point is to demonstrate the
  correction, not the hover.
- Recovery placements are staged BY HAND before each episode per the table.
- End every episode as v2 did (release into the funnel, jaws close, then next).
- Never move cameras; scene_check before the session; hard stop if hesitation
  creeps in from fatigue.
- Direction convention (clarified Aug 26, 2026 — declared before any NUDGE
  episode was recorded): NUDGE directions are in the FRONT-CAMERA image frame,
  the same frame as "cap left" (left = toward the image's left edge, where the
  cap points). "toward arm" / "away" = along the line from the tube to the
  arm base. The tube is PLACED at the offset by hand — never knocked there.
